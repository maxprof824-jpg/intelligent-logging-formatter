# Review audit

These records preserve focused peer checks, original judgments and the reasons for any changes. The [index](INDEX.json) maps their original working references to the exact public files and hashes. The [final qualitative review](../V3-QUALITATIVE-REVIEW.json) contains the adopted counts and case reasoning.

Reviewers used frozen source checklists and assessed displayed facts and suggestions. Optional advice was not charged as a necessary repair merely because its value was uncertain. Restoring a fact and cleaning up its overlapping question count as one logical correction.

Model labels were hidden where practical, but this was AI-assisted review with prior familiarity and root access to labeled execution progress. An IT07 peer note also discloses incidental raw-output exposure. It is not independent user validation, a fully blinded study, or measured editing time.
