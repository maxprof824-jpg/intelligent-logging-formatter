# Historical release records

These files preserve earlier release metadata. [PACKAGE-MANIFEST-V25.json](PACKAGE-MANIFEST-V25.json) describes the exact 2.5 archive payload, before candidate training. Its training-status fields do not describe later experiments.

Each newer downloadable ZIP contains its own `PACKAGE-MANIFEST.json`, recording the files actually included in that archive. The release's `SHA256SUMS.txt` identifies the complete ZIP bytes.
